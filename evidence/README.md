# Evidence policy

`evidence-manifest.csv` is the index of every artefact a catalog claim rests on: one row per
artefact with its evidence ID, the detection it belongs to, the capture time (UTC), a type, the
in-repository path, a description, the SHA-256 of the file, and a reviewed flag. The write-ups
and `telemetry/validation-matrix.csv` refer to artefacts by evidence ID, never by path alone.

## How rows get there

- Rows of type `sigma-rule`, `compiled-query` and `telemetry-fixture` are generated by
  `scripts/build_evidence_manifest.py` from `detections/catalog.yml` for every detection that is
  `fixture-validated` or `validated`. The CI `catalog` job runs it with `--check` and fails if any
  hash or row differs from the committed artefacts, so an edited rule or fixture cannot keep an
  old evidence row. An unchanged artefact keeps its original capture date.
- Rows of type `ci-run` (`EV-CI-RUN-0001`) are added by hand after a green run and preserved by
  the generator; they carry a URL, not a hash.
- Rows the isolated-VM run will add — **none exist yet**: sanitised exported Sysmon/Security
  events (`EV-DET-00N-VM-POS`, `EV-DET-00N-VM-NEG`) and screenshots of the alert in context. The
  generator must learn to preserve those types before the first one is added
  (`telemetry/atomic-test-plan.md`, "Promotion to `validated`").

## Sanitisation rules for public evidence

- Raw exports stay in `evidence/raw/` (gitignored) and never leave the lab host.
- A public item contains only lab identities: fictional hostnames and users, IP addresses in the
  lab ranges (`10.10.x.x`), no SIDs or machine GUIDs that could identify a real machine. The VM is
  disposable, so real identifiers should not exist — check anyway.
- No credentials, tokens, or memory dumps. An LSASS dump, or anything derived from one, is never
  published or hashed into the manifest.
- Screenshots show the event, rule or alert context and nothing else on screen.
- Each public item is named by an immutable evidence ID, hashed into the manifest in the same
  commit, and referenced from the write-up and the validation matrix.
